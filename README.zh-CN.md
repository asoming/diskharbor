# 盘清

[English](README.md) · [简体中文](README.zh-CN.md) · [GitHub](https://github.com/asoming/diskharbor)

盘清是一款本地运行的桌面磁盘空间分析工具。查看空间被什么占用，检查文件与文件夹，并在移入系统回收站前核对具体文件。

**中文名：** 盘清 · **英文名：** DiskHarbor

## 项目状态

**0.1.0-alpha.1 — 早期 Linux alpha。** Electron 44 应用已在 Ubuntu 22.04 x86_64 开发环境运行，启用渲染进程沙箱，生产资源通过应用自身协议加载。Windows 和 macOS 的原生运行、打包、兼容性及签名尚未验证。

首个稳定版计划在 Linux、Windows 和 macOS 提供相同核心流程。当前 alpha 不代表已经完成跨平台支持。

## 已实现功能

- **空间概览：** 展示真实扫描结果与文件分类，分别显示磁盘占用和文件逻辑大小。
- **文件浏览：** 可展开的文件树，支持懒加载、分页、虚拟行、键盘导航、排序、搜索，以及大小和分类筛选。
- **文件详情：** 查看元数据与路径，在系统文件管理器中定位项目，复制路径。
- **确认后清理：** 手动选择普通文件，审阅处理清单，通过系统原生对话框确认后，将符合条件的文件移入回收站。操作前再次验证文件身份；回收失败不会转为永久删除。
- **结果记录：** 本地保存逐项处理结果与卷可用空间的实际变化。移入同一卷的回收站通常不会立即释放空间。
- **本地双语使用：** 提供中英文界面，无需账号，不上传扫描得到的文件名、路径或文件内容。

## 从源码运行

推荐使用 **Node.js 24，最低要求为 22.12**，并安装 npm。在仓库目录运行：

```bash
npm ci
npm run dev
```

构建生产界面并通过 Electron 运行：

```bash
npm run build
npm start
```

`npm run preview` 仅提供浏览器界面预览，不能扫描磁盘或执行文件操作；这些流程需要在 Electron 应用中使用。

## 当前限制

- 尚未实现应用缓存自动清理、目录清理、重复文件检测和扫描快照。
- 文件详情仅展示元数据；尚未提供完整内容预览、深色模式、完整错误信息翻译及应用内恢复界面。
- 实际占用不包含目录自身元数据；尚未识别 APFS 共享块及云占位文件状态。系统回收接口按路径操作，复核无法消除所有文件系统竞态。操作记录在每批结束后保存，尚不保证执行中崩溃后的完整恢复。
- Windows/macOS 的原生验证与签名待完成。Linux 单元测试通过不代表这些平台已受支持。
