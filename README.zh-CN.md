# 盘清

[English](README.md) · [简体中文](README.zh-CN.md)

盘清是一款面向普通用户、正在开发筹备中的桌面磁盘空间分析工具，帮助你看懂空间占用、浏览文件树、审阅清理建议，并核实操作结果。

**中文名：** 盘清 · **英文名：** DiskHarbor

## 项目状态

目前处于规划与设计阶段，尚未提供可运行应用、安装程序或发布版本。以下能力均为规划，尚未实现。

## 计划功能

- **空间概览：** 按分类、文件夹和文件查看磁盘占用。
- **文件树：** 逐层展开目录，按大小排序，搜索、筛选并查看文件详情。
- **清理建议：** 在选择操作前，了解内容用途、建议依据和可能影响。
- **操作确认：** 核对选中文件，在支持的情况下使用系统回收站；回收失败不会静默变成永久删除。
- **结果核验：** 区分已移入回收站的文件与真正释放的空间，报告跳过或失败的项目。
- **本地使用：** 扫描和浏览无需账号，不上传文件名、路径或文件内容。
- **中英双语：** 两种界面语言提供一致的操作流程。

## 平台支持

首个稳定版计划支持 **Linux、Windows 和 macOS**，三端具备相同的核心流程。从 Linux 开始开发，Linux alpha 可能先于跨平台稳定版提供。

权限、文件系统能力和回收站行为将遵循各平台习惯。平台支持情况和性能会在验证后说明。

## 界面风格

采用清晰的浅色界面、深青色强调、易读的空间分类、独立文件树页面，以及说明处理影响的清理建议。深色模式计划作为后续增强。
